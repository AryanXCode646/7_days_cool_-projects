DAY 02

Fractal Tree Studio & Mindful Breathing Guide

Generative branching mathematics coupled with practical utility: Disk Directory Tree Visualizer and Clinical 4-7-8 Stress-Relief Breathing Pacer for desk workers.

🌿 Live Interactive Fractal Tree Grower

Everyday Solutions & Features

📁 Disk Directory Tree Visualizer

Press F to scan your local project and render directories as branches, letting you visualize project depth organically.

🧘 4-7-8 Mindful Breathing Pacer

Press B to launch a rhythmic guide: Inhale 4s, Hold 7s, Exhale 8s to calm the nervous system during intense work sessions.

🍁 Seasonal Color Themes

Switch between Spring Blossom, Summer Green, Autumn Amber, and Winter Frost color themes.

Keyboard Shortcuts

KeyAction
FToggle Project Directory Tree Scanner (scans disk structure)
BToggle 4-7-8 Mindful Breathing Pacer with expanding guide rings
TCycle seasonal palettes (Spring, Summer, Autumn, Winter)
S / EExport high-resolution screenshot to disk
SpaceGenerate a new fractal tree iteration

Running Locally

python Day_2/faractor_tree_generator.py
