LUMINA ENGINE

Lumina Programming Language & Automation

A bilingual, lightweight programming language designed for everyday calculations, file automation, and productivity scripting with native standard library builtins.

Everyday Solutions & Key Features

💰 Budget & Expense Calculation

Run samples/budget_calculator.lum to calculate net savings, percentage allocations, and health targets.

📏 Universal Unit Converter

Run samples/unit_converter.lum for instant temperature, distance, and weight conversions.

📝 Persistent Daily Task Logging

Run samples/todo_tracker.lum to sync timestamps and active task items directly into disk text logs.

📊 Statistical Data Engine

Run samples/math_statistics.lum for list averages, min/max metrics, and Euclidean vector math.

Lumina Code Example

// Monthly Budget & Savings in Lumina
rakho income = 45000
rakho expenses = 28200
rakho savings = income - expenses
rakho savings_rate = (savings * 100) / income

bolo "Net Monthly Savings: $", savings
bolo "Savings Rate       : ", savings_rate, "%"

agar (savings_rate >= 30) {
    bolo "Status: EXCELLENT FINANCIAL HEALTH!"
}
