DAY 06

Neon Gesture Snake & Touchless PC Remote Controller

A dual-mode system allowing you to play neon arcade snake with hand gestures or switch into a touchless Windows remote controller for media playback, volume, and presentation slides.

Everyday Solutions & Features

🎛️ Touchless Windows Remote Control

Control Spotify, YouTube, VLC, and PowerPoint presentations with hand gestures without touching your keyboard.

🐍 Neon Gesture Snake Arcade

A cyberpunk neon snake game with particle food glows, dynamic difficulty, and camera gesture steering.

⚡ 1-Key Dual Mode Switch

Press M anytime to seamlessly switch between Game mode and Universal System Remote mode.

Gesture Control Mapping (Remote Mode)

GestureSystem Action Dispatched
☝️ 1 Finger (Index)Volume Up (Increases master Windows system volume)
✌️ 2 Fingers (Peace)Volume Down (Decreases master Windows system volume)
🤟 3 FingersPlay / Pause Media (Spotify, YouTube, VLC, Podcasts)
✋ Open PalmNext Slide / Page Forward ➡️ (PowerPoint, Keynote, PDF slides)
✊ Closed FistMute Audio 🔇 (Instant sound mute)
M KeyToggle between Arcade Snake and PC Remote

python Day_6/main.py
