DAY 01

Infinite Wallpaper Studio & Focus Manager

Generates infinite geometric, wave, noise, and gradient desktop artwork with direct Windows wallpaper setting integration, resolution presets, and daily motivational focus quotes.

🎨 Live Interactive Canvas Art Generator

Everyday Solutions & Key Features

🖥️ 1-Click Windows Wallpaper

Directly updates your Windows desktop background via native SystemParametersInfoW without opening settings.

📐 4K / 2K Ultra-HD Scaling

Switch between 1080p, 1440p 2K, and 4K UHD resolutions to export ultra-sharp wallpapers for any monitor.

🕒 Focus Clock & Motivational Quotes

Integrated HUD displaying current local time, calendar date, and curated deep-work affirmations.

Keyboard Shortcuts

KeyAction
WSet current generated art as active Windows Desktop Wallpaper
TCycle color themes (Cyberpunk, Sunset, Emerald, Ocean, Nordic Ice)
CToggle live desktop Clock & Daily Focus Quote overlay
RCycle target resolutions (1080p, 1440p 2K, 4K UHD)
SSave high-resolution PNG to saved_wallpapers/
PPause / Resume auto-generation interval
SpaceGenerate a new design immediately

Running Locally

python Day_1/infinte_wallpapers.py
