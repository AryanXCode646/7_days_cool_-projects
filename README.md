# 🚀 30 Days of Building Cool & Useful Applications

A curated collection of interactive, touchless, AI-powered, and everyday utility desktop tools built with Python, Pygame, PyQt5, OpenCV, and MediaPipe.

---

## 🌟 Application Suite Overview

| App | Name | Description | Key Features |
| :---: | :--- | :--- | :--- |
| **Day 1** | **Infinite Wallpaper Studio** | Generative geometric & focus desktop art | 1-click Windows wallpaper setter (`W`), 4K/2K presets (`R`), curated color themes (`T`), clock HUD (`C`) |
| **Day 2** | **Fractal Tree Studio & Mindful Guide** | Disk tree visualizer & breathing pacer | Real folder hierarchy visualizer (`F`), clinical 4-7-8 mindful breathing guide (`B`), high-res export (`S`) |
| **Day 3** | **Swarm Ecosystem & Genetics** | Artificial life & epidemic modeling | Interactive obstacle drawing (Right-click), food placing (Left-click), herd immunity simulation (`E`), CSV export (`X`) |
| **Day 4** | **Ergonomics & Privacy Avatar** | Desk health & vision tracker | Head-tilt & slouching alerts, blink-rate / 20-20-20 rule monitor, privacy avatar anonymizer (`A`) |
| **Day 5** | **AirDraw Pro** | Touchless whiteboard for presentations | Geometric shape auto-beautifier (`A`), presentation whiteboard (`W`) & darkboard (`B`), undo/redo (`Z`/`Y`) |

## 🛠️ Quick Installation & Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/AryanXCode646/30_Days_challenge_of_building_something_useless_but_cool.git
   cd 30_Days_challenge_of_building_something_useless_but_cool
   ```

2. **Create & Activate Virtual Environment:**
   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .\.venv\Scripts\Activate.ps1
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install pygame opencv-python mediapipe PyQt5 numpy matplotlib requests
   ```

4. **Launch Any App via Unified Launcher:**
   ```bash
   run_launcher.bat
   ```
